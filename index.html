01

Seerah QA Bot

★ Hackathon Winner Live

Questions about the Seerah need answers grounded in authenticated sources — generic LLM responses can be unsourced or drift into out-of-scope religious rulings.

Approach

Hybrid retrieval over a curated Seerah corpus: BM25 keyword search combined with semantic search, with citation validation enforced in code rather than prompts.

Details

Pre-retrieval blocking of out-of-scope religious rulings; trilingual queries (English, Urdu, Roman Urdu); a baked-in corpus fallback so answers keep working when external APIs are unavailable.

Demonstrates

A source-grounded QA system with deterministic safety and citation checks — 1st place at AI Seerathon 2026.

02

HVAC Revenue Recovery System

Live demo

HVAC contractors lose potential revenue when customer estimates go unbooked and past leads go dormant — manual follow-up is inconsistent and easy to forget.

Approach

A multi-tenant SaaS-style workflow that surfaces dormant leads and unbooked estimates, drafts AI-generated SMS outreach, and routes every message through human approval before sending.

Details

HMAC-SHA256 webhook verification, Supabase Row Level Security, append-only audit logging, and circuit breakers that fail closed. Integrations with ServiceTitan and Twilio. Automated test suite; 22 SQL migrations.

Demonstrates

Production-style safeguards around LLM-generated customer outreach: human-in-the-loop control, tenant isolation, and auditable messaging — delivered through structured AI-assisted development.

How I Build AI-Powered Products

My work is not "open a tool and write a prompt." Each project follows a disciplined path from problem to verified delivery.

  1. 01

    Understand the problem

    Clarify the user or business need before touching any tools.

  2. 02

    Define requirements

    Turn the need into scope, constraints, and acceptance criteria.

  3. 03

    Break it down

    Split the system into manageable components with clear boundaries.

  4. 04

    Reason about architecture

    Work through data flow, APIs, integrations, and technical trade-offs.

  5. 05

    Specify and guide implementation

    Write structured specs that drive AI-assisted coding with precise intent.

  6. 06

    Review the output

    Check every result against the requirements and expected behaviour.

  7. 07

    Test and iterate

    Run tests, trace errors to root causes, and fix systematically.

  8. 08

    Validate before shipping

    Verify functionality, security, reliability, and safety — then consider it done.
